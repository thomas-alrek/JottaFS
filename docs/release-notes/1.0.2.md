## JottaFS 1.0.2

### New

- **Share links from Finder.** Control-click a file or folder on a
  Jottacloud disk and choose **Copy Jottacloud Link**. JottaFS shares the
  item and copies the link. Anyone with the link can open the item. For an
  item that is shared, **Stop Sharing Jottacloud Link** removes the link.

  To use this, turn on the JottaFS Finder extension one time. JottaFS asks
  you, or go to **JottaFS → Settings → Finder** and click **Turn On**.
- **Download cache.** JottaFS keeps recently downloaded file data on your
  Mac. When you open a file again, it opens immediately. Jottacloud sends
  downloads at approximately 5–7 MB/s, so this is the only way to read faster
  than that.
- **Settings window** (**JottaFS → Settings**, or ⌘,):
  - Select the size of the download cache: Off, or 256 MB to 8 GB. The
    default is 1 GB.
  - See how much of the cache is in use.
  - Click **Clear Cache** to delete the cache.
  - Turn on the Finder extension.
- **Same names.** If you mount two locations with the same name, for example
  **Desktop** from two computer backups, the second disk gets the name
  **Desktop (2)** in Finder. A name that you set in **Advanced** is not
  changed.

### Faster

- Small files (4 MB or smaller) download in one request. Folders of
  documents and photos open faster.
- Uploads start sooner. JottaFS calculates the checksum while a file is
  written, so it does not read the file again before the upload.

### Notes

- The download cache is deleted when you restart your Mac. When the cache is
  full, JottaFS deletes the oldest data first.
- The cache does not change your files in Jottacloud.

### Known limits

- If a file or folder is added on jottacloud.com or on a different device
  after you opened its folder, Finder can show the item but not open it. To
  fix this, unmount the disk and mount it again.
- You cannot rename the disk in Finder. Use **Advanced** in JottaFS.
- The maximum file size for a write is 2 GiB.

### Requirements

- A Mac with Apple silicon and macOS 27 or later.
- A Jottacloud account.
