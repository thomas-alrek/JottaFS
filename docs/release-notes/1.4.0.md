## JottaFS 1.4.0

### New

- **Menu commands.** The **File** and **Location** menus have the actions of
  the selected location, with keyboard shortcuts: New Backup Device
  (Shift-Command-N), New Location (Command-N), Mount or Show in Finder
  (Command-O), Unmount (Command-E), Mount at login, Rename, Move to Trash
  (Command-Delete) and Delete Backup Device.
- **Notification for names that Jottacloud cannot store.** When you copy or
  rename an item with a character such as `?` or `:` in its name, Finder
  only shows "error code -50". JottaFS now also shows a notification with
  the names of the items, so that you know which items to rename.
- **Update notification.** While JottaFS is closed, it checks for a new
  version about every 12 hours and shows a notification when there is one.
  Click the notification to open JottaFS and install the update.
- **Turn off update checks.** In **Settings**, turn off **Check for updates
  automatically** if you do not want JottaFS to check for new versions.

### Changed

- **Account in Settings.** Your name, your email and **Sign Out** are now in
  **Settings → Account**. The Settings window closes when you sign out.
- **New Backup Device** is now the **+** button in the toolbar of the window.
- **Backup device actions.** Click **…** in the header of a backup device to
  add a location or to delete the backup device. The trash button is gone.
- **Mount at login** is now next to **Mount** and **Unmount**, with a
  shorter name.
- **Rename a mounted location.** You no longer have to unmount a location
  to rename it. The disk gets the new name the next time you mount it.
- **More like macOS.** The Settings window and the New Backup Device, New
  Location and Rename windows use the standard macOS layout. Most buttons
  are standard buttons, and **Unmount** is no longer red. The cache bar in
  Settings uses the full width.
- **More space for the list.** The explanation above the list shows only
  until you mount a location.

### Known limits

- Every file on a Jottacloud disk can be run, because Jottacloud stores no
  file permissions. Finder shows files without a file extension (such as
  `README`) as Unix executables, and opens them in Terminal.
- Names with the characters `" * : < > ? | % \` cannot be used, because
  Jottacloud cannot store them. Rename the file, then copy it again.
- JottaFS keeps a full copy of a file on your Mac before the upload starts,
  because Jottacloud must know the checksum of the complete file first. Your
  Mac must have free space for the largest file that you copy. Files upload
  one at a time.
- If you stop a copy in Finder, Finder deletes the files that it already
  copied one at a time. This can take some time for a large folder.
- Finder does not show changes that you make on jottacloud.com or on a
  different device until it reads the folder again. Close and open the
  folder, or unmount the disk and mount it again.
- You cannot rename the disk in Finder. Control-click the location in
  JottaFS and choose **Rename** instead.
- A backup device without locations does not show in JottaFS. If you move
  the last location of a backup device to the trash, the backup device stays
  in Jottacloud. To remove it too, delete the backup device instead.
- The update notification needs you to be signed in. When you are signed
  out, JottaFS checks for updates only while it is open.

### Requirements

- A Mac with Apple silicon and macOS 27 or later.
- A Jottacloud account.
