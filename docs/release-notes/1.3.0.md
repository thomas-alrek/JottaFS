## JottaFS 1.3.0

### New

- **Make your own backup devices.** Click **New Backup Device** to make a
  backup device with a location that you can mount at once. It shows under
  Backup on jottacloud.com, like the backup of a computer.
- **Add locations.** Click **+** in the header of a backup device to add a
  location to it.
- **Remove locations and backup devices.** Control-click a location and
  choose **Move to Trash**: the location and its files move to the
  Jottacloud trash, where you can restore them. Click the trash button in
  the header of a backup device to delete it with all its locations and
  files; this cannot be undone. JottaFS unmounts mounted locations first,
  and removes nothing if a location cannot be unmounted.
- **Context menu for locations.** Control-click a location to mount or
  unmount it, show it in Finder, mount it at login, add a location, rename
  it or move it to the trash.

### Changed

- **Rename instead of Advanced.** The Advanced window is gone. To give a disk
  a different name in Finder, Control-click the location and choose
  **Rename**.
- **Ready to use.** When the window opens, the location list is selected, so
  you can use the arrow keys and Return at once.
- **Less empty space** at the top and bottom of the window.
- **Norwegian:** menu items and buttons no longer have a space before "…".

### Known limits

- Every file on a Jottacloud disk can be run, because Jottacloud stores no
  file permissions. Finder shows files without a file extension (such as
  `README`) as Unix executables, and opens them in Terminal.
- Names with the characters `" * : < > ? | % \` cannot be used, because
  Jottacloud cannot store them. Finder then shows "an unknown error
  occurred (error code -50)". Images that you save from websites often
  have a `?` in the name. Rename the file, then copy it again.
- JottaFS keeps a full copy of a file on your Mac before the upload starts,
  because Jottacloud must know the checksum of the complete file first. Your
  Mac must have free space for the largest file that you copy. Files upload
  one at a time.
- Finder does not show changes that you make on jottacloud.com or on a
  different device until it reads the folder again. Close and open the
  folder, or unmount the disk and mount it again.
- You cannot rename the disk in Finder. Control-click the location in
  JottaFS and choose **Rename** instead.
- A backup device without locations does not show in JottaFS. If you move
  the last location of a backup device to the trash, the backup device stays
  in Jottacloud. To remove it too, delete the backup device instead.

### Requirements

- A Mac with Apple silicon and macOS 27 or later.
- A Jottacloud account.
