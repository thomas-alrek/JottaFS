## JottaFS 1.5.0

### New

- **A whole device as one disk.** Click **…** next to a device (Jottacloud
  or a backup device) and choose **Mount as One Disk**. The device shows in
  Finder as one disk, and each of its locations is a folder on it. You can
  move files and folders between the locations. Jottacloud moves them, so
  nothing is copied.
- **Change locations in Finder.** On the disk of a backup device, the
  folders at the top are the locations. Make a new folder to make a new
  location. Rename a folder to rename the location. Move a folder to the
  Trash to move the location to the Jottacloud trash, and use **Put Back**
  to get it back.
- **Devices in the list.** Each device now has its own row, with its
  locations under it. Click the arrow to show or hide the locations. A
  device shows its locations at start only when one of them is mounted.
- **Device descriptions.** Control-click a device and choose **Edit
  Description** to give it a description. You can also type one when you
  make a new backup device. The description shows under the name of the
  device.

### Fixed

- A location that you moved to the trash stayed in the list.

### Known limits

- Every file on a Jottacloud disk can be run, because Jottacloud stores no
  file permissions. Finder shows files without a file extension (such as
  `README`) as Unix executables, and opens them in Terminal.
- Names with the characters `" * : < > ? | % \` cannot be used, because
  Jottacloud cannot store them. JottaFS shows a notification with the names.
  Rename the file, then copy it again.
- JottaFS keeps a full copy of a file on your Mac before the upload starts,
  because Jottacloud must know the checksum of the complete file first. Your
  Mac must have free space for the largest file that you copy. Files upload
  one at a time.
- If you stop a copy in Finder, Finder deletes the files that it already
  copied one at a time. This can take some time for a large folder.
- Finder does not show changes that you make on jottacloud.com or on a
  different device until it reads the folder again. Close and open the
  folder, or unmount the disk and mount it again.
- You cannot rename the disk in Finder. Control-click the location in
  JottaFS and choose **Rename** instead.
- A backup device without locations does not show in JottaFS. If you move
  the last location of a backup device to the trash, the backup device stays
  in Jottacloud. To remove it too, delete the backup device instead.
- jottacloud.com cannot restore a location from the trash ("Restore
  unavailable"). To get it back, mount its backup device as one disk and
  use **Put Back** in Finder's Trash.
- On a device's disk, you cannot put files in the top folder. Put them in
  one of the locations.
- The description of a device is kept on this Mac only.
- The update notification needs you to be signed in. When you are signed
  out, JottaFS checks for updates only while it is open.

### Requirements

- A Mac with Apple silicon and macOS 27 or later.
- A Jottacloud account.
