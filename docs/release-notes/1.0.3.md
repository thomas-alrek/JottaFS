## JottaFS 1.0.3

### New

- **Install with Homebrew.** You can now install JottaFS with Homebrew.
  Add the tap one time, then install:

  ```sh
  brew tap thomas-alrek/jottafs https://github.com/thomas-alrek/JottaFS
  brew install --cask thomas-alrek/jottafs/jottafs
  ```

  JottaFS continues to update itself.

### Fixed

- **Mount at login when the network is not ready.** When you log in, JottaFS
  now waits for the network connection (for example, for Wi-Fi to connect)
  before it mounts your locations. If a mount fails because of the network,
  JottaFS tries again for up to 3 minutes. The JottaFS window opens only if
  the mount still fails, or fails for a different reason.

### Known limits

- Finder does not show changes that you make on jottacloud.com or on a
  different device until it reads the folder again. Close and open the
  folder, or unmount the disk and mount it again.
- You cannot rename the disk in Finder. Use **Advanced** in JottaFS.
- The maximum file size for a write is 2 GiB.

### Requirements

- A Mac with Apple silicon and macOS 27 or later.
- A Jottacloud account.
