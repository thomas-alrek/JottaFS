## JottaFS 1.0.1

### New

- **Mount more than one location at the same time.** Select a location and
  click **Mount**. Then select a different location and click **Mount**
  again. Each location shows in Finder as a separate disk. A green checkmark
  in the list shows which locations are mounted.
- **Mount at login for each location.** Select a location, then select
  **Mount automatically when I log in**. Do this for each location that you
  want to mount when you log in.
- **Unmount one location.** Select a mounted location and click **Unmount**.
  The other locations stay mounted.
- **Photos** has its own icon in the location list.

### Changes

- The location list is not locked while a location is mounted. The
  **Mount** and **Unmount** button shows the state of the selected location.
- **Sign Out** unmounts all mounted locations.
- **Advanced** settings apply to the selected location.

### Update from 1.0.0

JottaFS 1.0.1 can unmount a disk that 1.0.0 mounted. If you used **Mount
automatically when I log in** in 1.0.0, it stays on for the same location.

### Requirements

- A Mac with Apple silicon and macOS 27 or later.
- A Jottacloud account.
