## JottaFS 1.0.6

### Changed

- **The download cache is deleted when you unmount a disk.** JottaFS keeps
  recently downloaded file data on your Mac, so that files you open again
  open immediately. When you unmount a disk (in JottaFS or with Eject in
  Finder), JottaFS now deletes the data of that disk. When you mount it
  again, its cache is empty. The size that you set in **JottaFS → Settings**
  is for all disks together, and the whole cache is still deleted when you
  restart your Mac.

### Fixed

- **Settings shows the correct cache size.** **In use** in **JottaFS →
  Settings** counts only downloaded file data.

### Known limits

- Finder does not show changes that you make on jottacloud.com or on a
  different device until it reads the folder again. Close and open the
  folder, or unmount the disk and mount it again.
- Your Mac must have free space for each file while it uploads.
- You cannot rename the disk in Finder. Use **Advanced** in JottaFS.

### Requirements

- A Mac with Apple silicon and macOS 27 or later.
- A Jottacloud account.
