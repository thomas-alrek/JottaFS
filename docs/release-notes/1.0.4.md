## JottaFS 1.0.4

### Fixed

- **Large files.** There is no longer a 2 GiB limit for files that you copy
  to a Jottacloud disk. A file can be as large as your Mac has free space
  for while it uploads.
- **Less disk space during copies.** JottaFS keeps a copy of a file on your
  Mac until the upload is complete, because Jottacloud must know the
  checksum of the complete file first. JottaFS now deletes this copy as soon
  as the upload is complete. When you copy many files, for example from an
  SD card, your Mac needs free space for approximately one file at a time.
  JottaFS never deletes the file that you copied from.
- **Clear error when the disk is full.** If your Mac does not have enough
  free space for a file, the copy stops and Finder tells you that there is
  not enough space.

### Known limits

- Finder does not show changes that you make on jottacloud.com or on a
  different device until it reads the folder again. Close and open the
  folder, or unmount the disk and mount it again.
- Your Mac must have free space for each file while it uploads.
- You cannot rename the disk in Finder. Use **Advanced** in JottaFS.

### Requirements

- A Mac with Apple silicon and macOS 27 or later.
- A Jottacloud account.
