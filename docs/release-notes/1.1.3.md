## JottaFS 1.1.3

### Fixed

- **Copied files no longer show as 0 bytes.** Sometimes a file that you
  copied to a Jottacloud disk showed as 0 bytes and could not be opened,
  although it was on Jottacloud. This happened most often with Finder.
  Before, you had to unmount the disk and mount it again. Now the file shows
  its correct size when the copy is done.
- **Finder no longer stops responding when an upload fails.** On a poor
  network connection, a failed upload could make Finder stop responding for
  many minutes, and you had to stop JottaFS. Now an upload that does not
  progress stops after about a minute, and Finder shows that the copy
  failed. A slow upload that keeps progressing continues. After a failed
  upload, JottaFS waits a short time before it tries again on its own.
- **JottaFS no longer stops during large copies.** When you copied large
  files, JottaFS could stop working after an upload, and Finder's copy
  never finished. You had to stop JottaFS. Now this does not occur.
- **Safari can save downloads to a Jottacloud disk.** Before, a download
  from Safari to a Jottacloud disk always failed with "Cannot move file".
  The downloaded file stayed in a `.download` folder. Now the download
  completes as usual.
- **Deleting a file stops its upload.** Before, when you deleted a file
  that was uploading, JottaFS waited for the upload to finish first.
- **A new file stays in the folder during a long upload.** Before, a large
  file could disappear from the Finder window during its upload, and show
  again when the upload was done.

### Known limits

- Names with the characters `" * : < > ? | % \` cannot be used, because
  Jottacloud cannot store them. Finder then shows "an unknown error
  occurred (error code -50)". Images that you save from websites often
  have a `?` in the name. Rename the file, then copy it again.
- JottaFS keeps a full copy of a file on your Mac before the upload starts,
  because Jottacloud must know the checksum of the complete file first. Your
  Mac must have free space for the largest file that you copy. Files upload
  one at a time.
- Finder does not show changes that you make on jottacloud.com or on a
  different device until it reads the folder again. Close and open the
  folder, or unmount the disk and mount it again.
- You cannot rename the disk in Finder. Use **Advanced** in JottaFS.

### Requirements

- A Mac with Apple silicon and macOS 27 or later.
- A Jottacloud account.
